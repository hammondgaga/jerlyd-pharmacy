# Public Assets

This folder contains static assets served by Next.js.

## Logo Setup

To add the Jerlyd Pharmacy logo to the navbar:

1. Place your logo image file named **`logo.jpg`** in this directory
2. The logo should be:
   - Format: JPEG (.jpg) or PNG (.png)
   - Dimensions: At least 160px wide × 48px tall (or larger for better quality)
   - Aspect ratio: Approximately 3.3:1 (landscape format)
   - File size: Under 100KB recommended

3. The logo will automatically appear in the site header on both the main portal and password reset page
4. If the image fails to load, a fallback SVG icon will be displayed

The navbar is configured to display the logo at 48px height on desktop and 36px on mobile.
